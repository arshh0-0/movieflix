# 🎬 MovieFlix

MovieFlix is a modern movie discovery web application built with **React** and **Vite**. Browse movies, explore details, and enjoy a clean, responsive interface designed for movie lovers.

## 🚀 Features

* 🎥 Browse and discover movies
* 🔎 Search for movies
* ⭐ View movie ratings and information
* 📖 Explore detailed movie information
* 📱 Responsive design for desktop and mobile
* ⚡ Fast development and production builds with Vite
* 🔥 React-powered user interface
* ♻️ Hot Module Replacement (HMR) during development

## 🛠️ Tech Stack

* **React** – Frontend UI
* **Vite** – Development server and build tool
* **JavaScript** – Application logic
* **CSS** – Styling and responsive design
* **ESLint** – Code quality and linting

## 📦 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/arshh0-0/movieflix.git
```

Navigate to the project directory:

```bash
cd movieflix
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
